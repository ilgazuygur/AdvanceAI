Advanced AI · Assignment 01

Teach an Agent to Learn

Can an agent learn to cross a frozen lake? I used Gymnasium and Q-learning to train an agent to reach the goal while avoiding holes, then compared its performance with an agent that moves randomly.

The environment

FrozenLake is a 4×4 grid with a starting tile, frozen tiles, holes, and a goal. The agent can choose left, down, right, or up.

The lake is slippery, so an action does not always move the agent in the intended direction. Reaching the goal gives a reward of 1; all other transitions give 0.

How the agent learns

  • Remember: a Q-table stores a value for each state and action.
  • Explore: epsilon-greedy selection mixes random actions with the best known actions.
  • Update: rewards and estimated future values improve the table after each step.
  • Evaluate: the trained agent chooses the highest Q-value without further learning.

Three experiments, one changed variable

I changed the number of training episodes while keeping the other settings fixed: alpha = 0.8, gamma = 0.95, initial epsilon = 1.0, epsilon decay = 0.995, and minimum epsilon = 0.01.

Each agent was evaluated over 100 episodes.

Experiment 3 5,000 0.8 0.95 1.0 72%

Random baseline average reward: 0.01 per episode. The later 73% result belongs to a separate training run used to save the demonstration agent.

What changed, and why?

All three Q-learning experiments performed better than the random baseline. However, more training did not produce a steady improvement: the 3,000-episode run performed worse than the 1,000-episode run.

Random exploration and slippery movement can produce different outcomes between runs. Repeating each experiment with multiple random seeds would help determine whether the differences are consistent.

Learning or luck?

I evaluated each trained agent over 100 episodes instead of judging it from one successful game. The Q-learning experiments achieved success rates of 58–72%, compared with 1% for the random agent. During evaluation, the agent used its learned Q-table without exploration or further updates, which supports the conclusion that its learned action choices were useful. However, repeated training and evaluation with multiple random seeds would provide stronger evidence and help measure how consistent the improvement is.
